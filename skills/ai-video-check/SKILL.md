# AI 视频自检

用代码做视频，最常见的失败不是代码跑不起来，而是代码跑通了、画面却是坏的：字压字、字看不清、第一帧空白、某一段卡住、整片没声音、观众看不懂。这些问题只有看真实渲染出来的文件才会发现。

这套规则来自 JellyPop的实验室 做过的十几支 AI 代码视频，每一条都是真实踩过的坑。

## 铁律

**说做好了之前，先看实际画面。** 代码能跑、预览正常、检查命令通过，都不等于成片没问题。必须打开渲染出来的 mp4，抽帧看，再说完成。没看过的部分，交付时明确说"这一段我没检查"。

## 流程

### 1. 动手前先定三件事

写第一行代码之前，先定并写下来：

- 横屏还是竖屏，分辨率，时长。
- 配色：背景、主色、一个强调色。不用纯黑纯白。
- 字体：中文字体和英文字体各一个，用开源授权的字体。视频字号不能按网页来：1080p 横屏正文字幕至少 44px。

再写一句话故事：主角是谁，想要什么，最后怎样。写不出来就先别做画面。

### 2. 先做一小段

先只做前 5 到 10 秒，渲染出来，按第 4、5 步检查，给用户看过再做整片。不要一次做完整条再回头改。

### 3. 用工具自带的检查

- HyperFrames：每次渲染前跑 `npx hyperframes check`，零 error 才渲染。
- Remotion 或其他：没有统一的检查命令，就靠第 4 步的脚本和第 5 步的抽帧。

### 4. 机器检查渲染出来的文件

```bash
bash <这个 skill 所在的文件夹>/scripts/render_check.sh <video.mp4> [预期时长秒数]
```

需要 ffmpeg（Mac 上：先装 Homebrew，再 `brew install ffmpeg`）。HyperFrames 和 Remotion 都还需要 Node.js。

它会报告：时长、有没有音轨、响度、黑场、冻结（画面不动）、静音段，并生成一张抽帧拼图 `<video>_sheet.jpg`。

- 黑场或冻结从第 0 秒开始：通常是整片没渲出来（字体加载失败、脚本报错），不是"开场慢"。
- 文件体积异常小（15 秒 1080p 不到 1 MB）也是同一个信号。
- 时长和预期差超过半秒，算问题，要么改片子，要么跟用户说明原因。
- 有意的静止或静音可以保留，但要能说出为什么；结尾全静止加全静音不要超过约 3 秒，观众会以为卡住了。

### 5. 自己看帧

用读图的方式打开拼图（`<video>_sheet.jpg`），逐格看：

- 文字有没有互相压住，有没有压在画面主体上。
- 文字和背景对比够不够，小字在手机上还能不能读。
- 每个转场前后各看一帧，上一幕的东西有没有走干净。
- 第 0 帧不能是空白、全虚或只有背景。
- 竖屏视频的关键内容避开底部 25% 和右侧 12%（平台按钮和标题在那里）。

怀疑某一处时，单独截那一帧原尺寸看，不要只看缩略图。

### 6. 盲测

做视频的会话、读过需求的评审，都已经知道这支片"应该"讲什么，所以都会觉得能看懂。必须找一个什么都没看过的人。

派一个全新的子代理，只给它按时间顺序排好的抽帧拼图（每张图下写时间），不给需求、剧本、代码。如果片子的意思一部分在声音里，附一份声音清单：按时间写听得到什么，不写解读。然后问它：

1. 按顺序讲一遍发生了什么。
2. 主角是谁，想要什么。
3. 最后怎样，结尾的字写了什么，想说什么。
4. 哪些地方没看懂（写时间）。

它复述的故事对不上第 1 步那句话，就不算完成。它说没看懂的地方，优先修。

### 7. 交付时说清楚

交付时说明：检查了什么、用什么查的、哪些没查（比如你听不到声音，就说配乐需要用户自己听）。不说"应该没问题"。

## 代码渲染常见坑

| 现象 | 原因和做法 |
|---|---|
| 渲染出来整片空白，预览却正常 | 渲染时字体或资源路径被改写、脚本报错。看渲染日志里的报错，跑第 4 步的冻结检测 |
| 某几帧字幕在清楚和模糊之间闪 | `filter: blur()` 配了会过冲的缓动（back、elastic），推出负数无效值。blur 单独用 `power2.out` |
| 无限循环的背景动画让后面的动画越来越晚 | 不用无限重复，按场景长度算够次数 |
| 玻璃、毛玻璃效果看起来只是一块淡色平板 | 玻璃背后要有明暗不同的东西可以折射 |
| 镜头推到画面一角，中途掠过一片空白 | 先让目标点在屏幕上走直线到落点，再反算镜头位置 |
| 画面意思只靠一行小字解释 | 盲测时假设小字不存在；会被读反就把它升成主文字 |
| 用代码画真人的脸、手 | 基本画不像。需要真人或真实场景，就用真实照片、实拍素材，或交给视频生成模型 |
| 合成音乐不连贯、高音刺耳 | 先出一张频谱图看；需要好听的配乐，用乐器采样或正规曲库，不要全靠代码合成 |
| 两个渲染同时跑 | 互相拖慢好几倍，一个一个来 |

## 越用越准

每次踩到新坑，把它加进上面的表：现象、原因、做法，一行。下次就不会再犯。
