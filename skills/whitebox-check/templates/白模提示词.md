# 让 AI 写 Blender 白模的提示词（复制给你的 AI 编程助手）

把【】里的内容换成你自己的。电脑上先装好 Blender（免费，blender.org 下载）。

---

请帮我写一个 Blender Python 脚本，用命令行后台运行，生成一条白模动画，用来给 AI 视频模型当运镜参考。

【画面】一镜到底，【15】秒，16:9，24 帧。
【故事】【一个小女孩在古城屋顶扔出一架纸飞机，镜头跟着纸飞机穿过小巷，飞出巷口越过栏杆看到大海，向左沿海岸飞，沿悬崖俯冲掠过瀑布，贴着海面惊起一群白鹭，掠过一条挥手的渔船，最后纸飞机飞向远海，镜头自己爬升右转，停在悬崖小镇和瀑布的远景。】
【镜头风格】第一人称 FPV 穿越机视角，有无人机穿梭的感觉，但转弯要顺，不要急转。

要求：
1. 所有东西都用简单的灰白方块、圆柱、球搭，不要贴图，不要颜色（水面可以用一种浅蓝灰）。人用「圆柱身体 + 球头 + 方块手臂」的小人，要有动作的手臂单独做动画。
2. 镜头用关键点（时间、位置、看向哪里）加平滑曲线插值，转弯时镜头稍微侧倾。每个镜头段的时间写在注释里，方便我说「第几秒改一下」。
3. 小物体（纸飞机、鸟、球）不要做成一个平面或一根线，要有一点厚度或 V 形，从侧面和背后也看得见。
4. 镜头不能穿进任何物体，离地面、水面至少 1.5 米，离墙至少 0.8 米。
5. 转弯不要太快：镜头每帧转动尽量不超过 3 度。实在要急转的地方告诉我是第几秒。
6. 用 Eevee 渲染成 1280x720 的 mp4，同时保存 .blend 文件，文件名带版本号（v1、v2……）。
7. 渲染之前先在脚本里打印每秒的速度、每帧转了多少度、镜头离物体最近多少米，有问题先改再渲染。

我看完会直接告诉你哪里怪，比如「第 3 秒像撞墙了」「扔飞机的动作不对」，你改完再出下一版。

---

出完白模以后，用这个 skill 自检：

```bash
blender -b 你的白模-v1.blend --python scripts/check_blend.py -- --small 纸飞机物体名 --keyframes 5
```
